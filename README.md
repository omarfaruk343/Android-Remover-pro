# সিস্টেম অ্যাপ রিমুভার

ফোনের অপ্রয়োজনীয় (ব্লোট) সিস্টেম অ্যাপ রিমুভ করার Android অ্যাপ। UI বাংলায়।

## APK বানানোর উপায়
**১) Android Studio:** প্রজেক্ট ফোল্ডার Open করুন → Build > Build APK(s)।
**২) GitHub (কম্পিউটার ছাড়া):** ফোল্ডারটি নতুন GitHub রিপোজিটরিতে আপলোড করুন → Actions ট্যাব → "APK বিল্ড" → শেষে Artifacts থেকে APK নামান।

## কীভাবে কাজ করে
- রুট থাকলে: `pm uninstall -k --user 0 <প্যাকেজ>` দিয়ে সরাসরি রিমুভ।
- রুট না থাকলে: ADB কমান্ড তৈরি করে কপি করার সুযোগ দেয় (USB debugging চালু করে PC থেকে চালান)।
- রিস্টোর: `cmd package install-existing <প্যাকেজ>`; ফ্যাক্টরি রিসেটেও সব ফিরে আসে।
- জরুরি সিস্টেম প্যাকেজ (systemui, phone, settings, gms ইত্যাদি) 🔒 দিয়ে ব্লক করা।

> Android-এর নিয়মে সাধারণ অ্যাপ রুট/ADB ছাড়া সিস্টেম অ্যাপ আনইনস্টল করতে পারে না।
